Working modes

VS Code / GitHub Copilot

Open the repository, use Agent mode, attach SKILL.md and one scenario document. Workspace instructions apply the executive output conventions automatically.

Apply hubsp-ai-skill to the attached scenario document. Recommend the simplest viable Microsoft architecture and save the complete recommendation to doc/recommendation-output.md. Treat missing decision-critical information as explicit assumptions or validation gates; do not invent facts.

Claude Desktop

Package the repository as a custom skill ZIP. Progressive disclosure allows Claude to load the router first and supporting files only when needed.

Upload the skill → attach one scenario document → use the universal compact prompt → review the generated recommendation.

Microsoft Scout (Frontier preview)

Confirm preview enrollment and admin access. Install the skill, start a new conversation and keep auto-approve disabled while validating tool and data access.

Workspace + installed skill + scenario document → governed recommendation with explicit approval boundaries.
