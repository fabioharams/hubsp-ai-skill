## 5.1. Agent Access Methods to Fabric

**Summary:** Agents can query governed data in place, retrieve indexed content, consume semantic models, invoke a Fabric data agent, or call a controlled SQL, KQL, API or MCP tool. The selected strategy determines whether data remains at the source, is referenced through a Shortcut, is mirrored or materialized in OneLake, or is copied into a managed search index.

Use the selection matrix in [Data Consumption Strategies for AI Agents](05-fabric-data-consumption.md). Prefer built-in Work IQ, Foundry IQ, Fabric IQ, Fabric data agent and supported connector capabilities before custom retrieval code. Validate identity propagation, permissions, freshness, capacity, data movement, preview status and audit coverage for the complete path.
