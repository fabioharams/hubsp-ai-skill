# Microsoft Product and Technology Lifecycle Audit

> Status and source access date: **2026-11-17**. This register covers the Microsoft architectural dependencies, lifecycle-sensitive features, models and SDKs cited in this repository. Evidence comes only from Microsoft Learn, official Microsoft announcements and Microsoft-maintained repositories. It records unresolved source conflicts rather than inferring GA.

## Executive verdict

The low-complexity-first architecture policy remains valid. The September lifecycle snapshot needed these corrections:

- Work IQ in Copilot Studio is now GA for the Microsoft Copilot harness. Business apps workloads remain preview. Named Web IQ search, browse, Auto and Places endpoints are GA; Commerce is private preview.
- Fabric data agent and the read-only Fabric IQ MCP server are GA. Fabric IQ remains a preview workload. The separate Foundry Fabric IQ (OneLake Catalog) integration is preview; its legacy Microsoft Fabric tool became unsupported on **November 6, 2026**.
- Microsoft announced Purview Data Governance retirement on **November 12, 2026**. New accounts are blocked; support ends **November 12, 2027**. Purview Data Security and Compliance offerings continue.
- Foundry core and hosted agents are GA. Managed memory, agent guard rails, monitoring and recurring evaluation remain preview. Foundry Workflows retires **December 1, 2026**.
- Use stable, capability-specific SDKs and supported model versions. Replace the legacy Teams AI Library example and prefer Azure Managed Redis over the retiring Azure Cache for Redis.
- The Agent Governance Toolkit removed its commercial "Public Preview" label because it is an MIT open-source project. The separate ACS runtime still has prerelease packages. Neither implies a managed-service SLA.

No preview dependency should be approved for a critical production path solely because its parent platform is GA.

## Date interpretation rules

- A model version date is not necessarily its public announcement or GA date. This register preserves both when Microsoft publishes both.
- A roadmap target is not proof of release. A capability is marked released only when a current official page or release record confirms it.
- A parent platform's GA status does not promote preview child features to GA.
- GA, legacy, deprecated, retired, prerelease and open-source versioning are distinct states. A service can remain available while being deprecated, and a released SDK can call a preview service.
- When official sources conflict or omit a material status, record **Unconfirmed**, the conflicting evidence and a validation owner. Use a confirmed supported alternative for a critical production path.
- These checks cover lifecycle, not a fresh legal, pricing, quota, security-certification or regional-capacity audit. Historical review dates elsewhere remain unchanged unless the corresponding claim was rechecked.
- Region, cloud, model, SKU, quota, license and tenant rollout remain production validation gates after a feature reaches GA.
- Recheck this file before each production architecture approval and update both the status and access date when a source changes.
